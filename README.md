# 🐦 Sweta's Flappy Bird Game

A simple Flappy Bird game project created while learning and practising coding.

🔗 **Play the Game:** [Sweta's Flappy Bird](https://swetakumari7.github.io/sweta-flappy-bird/)

## About the Project
This is a small personal project built for practice and learning. The goal was to create a playable version of the classic Flappy Bird game.

## How to Play
- Press **Space** or click to make the bird fly.
- Avoid hitting the pipes.
- Try to get the highest score!
